# Preloaded art

Drop image files here and list them in `index.json`. The app reads the list when it opens.

Portraits: 512x512 JPG, named `portraits/<class>-<n>.jpg`.

```json
{"portraits":{"fighter":["portraits/fighter-1.jpg","portraits/fighter-2.jpg"],"elf":["portraits/elf-1.jpg"]}}
```

Class keys: cleric, dwarf, elf, fighter, halfling, magicuser, thief.
